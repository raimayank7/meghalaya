How the code SBIN0065354 is built

SBIN is the bank part: the letters of State Bank of India. The fifth character is always the digit 0. 065354 is the part that names this branch.

The MICR code 781002084 is the number printed along the bottom of this branch's cheques. 781 is the city (the same three digits that begin the PIN code 781022), 002 is the bank and 084 is the branch.
